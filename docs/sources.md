# データの取得元と利用規約の確認結果

2026-11-17 時点の調査結果。**新しい取得元の Collector を作る前に、この表を確認・更新すること。**

> 注意：調査した環境から多くのサイトに直接アクセスできず、利用規約の多くは検索結果の抜粋で確認した。robots.txt はすべて未確認。実装の前に原文を読み直すこと。

判定：**OK**＝実装してよい／**要契約**＝API キー・契約・運営者の許可が必要／**グレー**＝規約を確認できず、問い合わせが必要／**NG**＝規約で禁止、または避ける

## 実装済み

| 取得元 | 用途 | 方式 | 判定 | メモ |
|---|---|---|---|---|
| TCGdex | カード名鑑（日本語） | REST API（キー不要） | OK | データは MIT ライセンス。出典「TCGdex」を表示。画像の権利は株式会社ポケモン等にあるため再ホストせず、TCGdex の URL にリンクするだけにする |
| Cardmarket（TCGdex 経由） | 海外相場（EUR） | TCGdex のカード詳細の `pricing.cardmarket` | OK | Cardmarket 本体の API はプロ販売者限定。出典「Cardmarket（TCGdex経由）」を表示 |
| 欧州中央銀行（Frankfurter 経由） | 為替（EUR・USD→円） | REST API（キー不要） | OK | 出典「欧州中央銀行（ECB）」を表示。営業日に 1 回更新 |

## 契約・許可が必要

| 取得元 | 判定 | メモ |
|---|---|---|
| カードラッシュ | 要契約（提携） | データ利用ポリシー（cardrush.media/data_policy）で、提携していない者による自動取得・価格取得を明確に禁止。提携の相談窓口あり |
| 晴れる屋2 | グレー（要問い合わせ） | 規約に自動取得の明記は見当たらず、無断転載・再配布は禁止。商品 JSON を案内する llms-full.txt を公開しているので、相談しやすい相手 |
| ドラゴンスター、遊々亭、フルアヘッド、トレカキャンプ、magi | グレー | 規約を確認できなかった、または該当する条項がない。許可を取ってから |
| PriceCharting | 要契約（有料） | 日本語版ポケカを収録。公開サイトに表示するには商用ライセンスが必要 |
| Scrydex | 要契約（有料） | 日本語カードの API がある（作成中） |

## 使わない

| 取得元 | 理由 |
|---|---|
| ポケモンカード公式サイト | データの利用許諾は個人で楽しむ場合に限られる |
| スニーカーダンク | 規約でクローリング・スクレイピングを明示的に禁止 |
| メルカリ、ラクマ、Yahoo!オークション（落札相場） | 公式 API がなく、規約上の自動取得はできないか、ほぼできない |
| TCGplayer API | 新規の利用受付を停止 |
| eBay Marketplace Insights | 新規の利用不可 |
| pokemontcg.io | 英語版のみ。2027-03-01 に提供終了予定 |
